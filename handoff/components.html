1. Turn wrappers

Every message in the thread is wrapped in a .chat-turn. The variant modifier sets alignment (left/right), avatar position, and whether the children inherit a bubble or stand alone as cards.

.chat-turn--ai

AI message — sparkle avatar on the left, content beside it. No bubble chrome.

I’ll help you pick sources, sharpen angles, and draft posts. Attach a playbook (Voice, Brief, Brand) any time to make my suggestions sharper.

.chat-turn--user

User message — right-aligned You label stacked over a solid blue bubble.

You

Pull the strongest moments from the customer call and draft a post.

.chat-turn--ai.chat-turn--extraction / .chat-turn--clip-extraction

AI turn with NO sparkle avatar — the child card has its own leading glyph (pen, sparkles, bulb, file). Stacks vertically and gets a max-width.

Note on max-width. .chat-turn no longer carries a generic max-width. Only .chat-turn--user (560px) and .chat-turn--extraction (480px) are bounded. Other AI turns flow at the thread's natural width (740px via .session__assistant-thread > *).

9. Quick picker (inline question)

A one-question picker that overlays the composer. Built by renderPicker() and driven by inline-question.js. Same chrome, five modes — all previews below are rendered live from the real renderPicker(), so they never drift. Header carries an optional title, step label, subtitle, and back arrow.

.analyse__options — single select

Numbered rows; click jumps straight to the choice (chevron affordance).

.analyse__options--multi — multi select

Rows toggle on/off (check affordance); a Continue button submits the set.

.analyse__options--stepper — counters

Each row carries a − N + counter (0 opts out); the submit shows the summed total. Title + subtitle, and a Back button in the footer. Used by the "drafts per angle" step.

.analyse__option--input — free text

Trailing row swaps to a text input + send button for a typed answer.

.analyse__option--file — dropzone

Trailing row becomes a click/drop file zone (wraps a hidden file input).
