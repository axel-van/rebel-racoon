# Archie — Copy audit (Phase 1)

> **Status** — Phase 1 inventory. Per-string findings, severity flags, problem tags. No rewrite proposals here (those land in Phase 3, `copy-rewrites.md`).
>
> **Date** — 2026-05-22
>
> **Scope** — Every user-facing string in `src/`, `index.html`, plus any user-visible label seeded in `mocks.js`. Excludes admin-only chrome (`user-mode-chip.js`), CSS files (no `content:` strings detected), and dev docs (`AGENTS.md`, `README.md`, audit reports).
>
> **Methodology** — Direct file read across all 21,400 LOC of `src/`. Each row = one discrete user-facing string. Repeated patterns (e.g. pluralisation templates) captured once with their pattern signature. Concept-level findings live in the synthesis sections at the end.
>
> **Reference lexicon** (Phase 0 validated, used to flag drift):
> Session, Playbook, Tone of voice, Source, Idea, Draft, Regenerate, Pinned. Archie speaks **1st person**. Sentence case. No periods on short labels. No emojis in system copy. No "Oops" / "Please" / "Something went wrong" / "Click here". Overrides do not exist.

---

## Severity legend

- 🔴 **Bloquant** — breaks the lexicon, exposes jargon, breaks language consistency (FR/EN mix), wrong persona/voice, factually misleading, or violates Phase 0 absolute bans.
- 🟠 **Important** — concept drift (e.g. "context" alongside "playbook"), inconsistent capitalisation, missing punctuation rule, redundant or padded phrasing.
- 🟡 **Polish** — micro-cleanup (article use, plural fallback, slight tone mismatch).

# 21. Concepts à clarifier (synthesis)

The audit surfaced more drift than I expected. The Phase 0 lexicon needs Phase 2 to settle:

1. **`Outputs` is everywhere as a user-facing label** — topbar, status card, right-panel header — but Phase 0 picked `Ideas`. Either retire "Outputs" entirely, or formally elevate it to a new concept (the panel surfaces BOTH Ideas + Clips under one tab, so "Outputs" was technically chosen for that union). Decision needed in Phase 2.

2. **`Conversation` / `chat` is the dominant label in chrome** despite Phase 0 picking `Session`. This is the biggest concept-name battle in the codebase. Phase 2 must either:
   - flip every chrome surface to `Session`, or
   - retire `Session` and adopt `Conversation` as the lexicon term.
   - I lean toward **Conversation** post-audit — it's the user-facing surface name the codebase has converged on naturally. `Session` reads sysadmin-y for a creative tool.

3. **`Brief` / `Strategy brief` / `Brand theme` / `Voice profile`** — these are real sub-concepts of a Playbook. Should they be visible to the user as sub-labels, or fold under `Playbook`? Need a decision.

4. **`Context` is still everywhere in error toasts and confirms** — even though `Playbook` is the official term. This needs a sweep.

5. **`Themes` (video flow)** vs **`Ideas`** — Phase 0 picked Ideas. The video "extract themes" branch should be renamed to "extract ideas" or the concept retired.

6. **`Content ideas` / `Content Studio`** — legacy names from Composer. Should be removed.

7. **`Library`** appears as an eyebrow on /ideas and /contexts — never explained as a concept. Either name it (Top-level navigation = "Library", with Ideas & Playbooks inside) or drop it.

8. **`Working session` / `workspace`** — never used; OK.

9. **`brand` vs `Brand`** — capitalisation inconsistent. Pick one.

10. **`Generation preferences` (Settings)** — concept distinct from Playbook but never named in lexicon. Phase 2 needs to clarify their hierarchy:
    - Playbook = per-conversation voice/audience
    - Generation preferences = global tone/length/CTA defaults
    - Do they conflict? Override priority?

11. **`Image Voice` (Playbook brief panel)** — confusing name; means "brand visual identity extracted from website". Rename in Phase 2.

12. **`Custom additions` (chip helper)** vs **`Suggestions`** vs **`Other…`** — three terms for user-typed chips. Pick one.

# 22. Patterns / anti-patterns détectés

## Anti-patterns

1. **Echo verbatim of button labels as user-turn echoes** — `Skip`, `Continue`, `Use the chat title` posted as `<You>` bubbles. Reads weird (the user clicked, didn't say). Phase 3 should consider whether to echo at all, or echo with a more conversational equivalent.

2. **Verbal tic: `Got it`** — appears 6+ times across session.js and context-builder. Phase 0 voice is "clear and posed". Drop.

3. **Verbal tic: `Tweak`** — appears in 3 wizard summaries. Loose; "Refine" or "Edit" cleaner.

4. **Mock state leaking** — `(mock)`, `Coming soon`, `(preview only)`, `pinning the page surface first` — these are dev annotations exposed to users.

5. **AI attribution exposed** — Phase 0 §7.1 said attribution is implicit. Hits: `AI-suggested clips` eyebrow, `Rewrite with AI` aria-label, `the AI should know` placeholder.

6. **Fake exclamation marks** — `Bienvenue 👋`, `Bug reported!`, `Thanks for your feedback!`, `Looks great`. Phase 0 banned exclamatif.

7. **`Please` + emojis + "we're sorry"** — already flagged.

8. **Decorative ellipses** — `...` (3 dots, not `…`) in 3+ placeholders.

9. **Awkward `(s)` pluralisation** — Only in FR onboarding. Easy fix.

10. **Duplicate strings** — picker `title` often duplicates the AI bubble text just above. Reads redundant. Pattern: AI bubble has the question, picker title repeats it. Phase 3 should consider dropping picker title when intro carries the question.

11. **Inconsistent button labels for the same action**:
    - "Save" (rename modal) vs "Save changes" (playbook editor) vs "Save playbook" (brief panel)
    - "Delete" (sidebar row, confirm modal) vs "Delete source" (no) vs "Delete playbook" (no)
    - "Cancel" everywhere — OK, single style

12. **`...` vs `…` (typographic)** — mixed.

13. **`great` / `so much` / `truly` / `magic` / `awesome`** — gushy modifiers. Phase 0 voice is posed, not eager.

14. **Tap vs Click** — desktop product, `Tap to add a description` is wrong (brief panel voice profile).

15. **Title duplication in pickers** — many wizards declare a `title` _and_ push an AI bubble with the same text. Phase 3: pick one location.

## Patterns to keep

- **Conversational AI bubbles before pickers** — gives the wizard a chat feel. Keep.
- **Reading-mode read-only pills** — clean separation between "this is a chip you can toggle" and "this is the saved state".
- **Empty state with icon + title + body + CTA** — consistent across surfaces (per FIND-B1 in the code). Keep.
- **Toast + Undo action** for reversible operations — used consistently. Keep.
- **Confirm modal with `Keep editing` vs `Discard` (verb pairs)** — Phase 0-aligned. Keep.
